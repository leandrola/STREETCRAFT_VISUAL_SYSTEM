# Regression Policy

## Protected behaviors

A future feature cannot be accepted by sacrificing:
- Source Identity Preservation
- Minimum Necessary Transformation
- Camera source-lock precedence
- Fear City identity routing
- Semantic Text Lock
- Material Intensity Delta
- Occlusion Locks
- Reference isolation
- Archive authority boundaries

## Baselines

Baselines are versioned.

Updating a baseline is not the same as fixing a regression.

A baseline change requires:
1. explicit design decision,
2. changelog entry,
3. reason for changed expected behavior,
4. new benchmark evidence,
5. owner approval when Canon/identity behavior is affected.

## No benchmark laundering

Do not:
- delete a failing case to make the suite pass;
- weaken a threshold without documentation;
- replace a golden fixture silently;
- score generated self-labels as evidence;
- treat a new aesthetically pleasing output as a new baseline without review.
