# SVS 1.8.0 Release Notes

## Release focus
Regression & Benchmark Suite.

## New
- 39 benchmark cases across package integrity, CIL, camera, Fear City, hardening, Archive-aware runtime and visual identity.
- golden fixture hash registry
- governing-file baseline
- automated regression runner
- visual benchmark rubric and score calculator
- release PASS / REVIEW / FAIL policy

## Important
R2 visual benchmarks are intentionally marked pending until a real image-generation runtime produces candidate outputs.

SVS does not certify its own generated images by reading labels embedded in those images.
