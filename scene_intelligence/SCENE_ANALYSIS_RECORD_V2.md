# Scene Analysis Record v2 (SAR2)

SAR2 replaces a flat scene-summary mentality with an explicit entity/relationship model.

## Required sections
- `scene_id`
- `source_identity`
- `mode`
- `profile`
- `entities`
- `relationships`
- `action_plan`
- `identity_anchors`
- `unknown_locks`
- `reference_need_hints`
- `warnings`

SAR2 is an analysis artifact. It is not itself the final generation prompt.
