# Transformation Modes

T01 FAITHFUL REINTERPRETATION
Preserve composition, architecture, light and character. Very low invention.

T02 FRONTALIZATION
Migrate an oblique source toward frontal visual elevation while preserving architecture and proportions.

T03 CLEAN PLATE
Remove explicitly authorized temporary elements and reconstruct only from surrounding evidence.

T04 SCENE EXTENSION
Extend laterally/vertically. Inference freedom may rise away from source boundary only within budget.

T05 ATMOSPHERE TRANSFER
Modify time/weather/humidity/visual atmosphere while preserving spatial identity.

T06 FEAR CITY INTERPRETATION
Project the authored physical Fear City model into the world it represents. Preserve authored-world geometry and relationships. Translate model material behavior, scale cues, lighting and capture artifacts without redesigning the world.

T07 PERIOD RECONSTRUCTION
Transform a contemporary source toward an earlier target period while preserving permanent geometry. Historical specificity must scale with evidence.

T08 BACKDROP EXTRACTION
Create a buildable/printable facade-oriented image with corrected verticals, controlled perspective and reconstructed occlusions while preserving architectural DNA.
