# Golden Fixtures

Golden fixtures are stable benchmark inputs or previously validated outputs.

They are not all Canon.

Roles:
- `STYLE_REFERENCE_FIXTURE` — stable reference image used for classification/comparison.
- `CAMERA_GOLDEN_OUTPUT` — controlled same-building CG-A/CG-B evidence.
- `FEAR_CITY_SOURCE` — confirmed authored-world source views.

Fixture integrity is checked by SHA-256.

A fixture hash change is a benchmark event, not a harmless file replacement.
