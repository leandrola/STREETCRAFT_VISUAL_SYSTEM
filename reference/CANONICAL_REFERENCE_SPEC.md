# Canonical Reference System 1.1

Types:
CR-A MASTER CANON
CR-B TRANSFORMATION CANON
CR-C DOMAIN CANON
CR-D PROFILE CANON
CR-E NEGATIVE CANON
CR-F BOUNDARY CANON
DR DOCUMENTARY EVIDENCE

Authority: GOLD / SILVER / STUDY
Status: UNREVIEWED / ACCEPTED / CANONICAL / REJECTED
Only the human project owner can set CANONICAL.

Canonical Transformation Pair (CTP) is preferred when provenance is known: source → transformation intent → output.

Reference Card minimum fields:
id, title, authority, reference_type, source_domain, mode, profile, assets, preservation, transformation_budget, canon_scope, learn[], do_not_generalize[], failure_modes_avoided[], known_compromises[], compliance_score, status, provenance.

Provenance must distinguish SOURCE, INFLUENCE and OUTPUT. Influence is not source. Historical designations require proven identity.

Canon is scoped evidence. Never average the collection into a generalized aesthetic template.
