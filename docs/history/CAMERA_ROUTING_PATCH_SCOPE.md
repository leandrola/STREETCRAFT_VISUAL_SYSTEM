# Camera Grammar / Profile / Fear City Routing Patch

## Scope
This patch modifies only:
- Camera Grammar
- VP00 / VP01 / VP02 camera behavior
- VP03 camera handoff wording
- Auto-Routing toward Fear City
- package metadata / changelog

## Explicitly untouched
- Visual Canon
- Canon Candidates
- Documentary Evidence
- Fear City Vision
- SC-01..SC-66 rule set
- Transformation Modes
- Preservation Model
- schemas
- critic / self-correction logic
- Archive subsystem

## Formal decisions
1. Streetcraft's first three profiles no longer equate architectural discipline with strict frontality.
2. Two transformable architectural camera families are formalized:
   - CG-A Frontal-Oblique Architectural Immersion
   - CG-B Street-Level Oblique Monumentality
3. CG-S protects source camera when preservation outranks profile preference.
4. VP02 retires mandatory yaw≈0° and mandatory one-point frontal perspective.
5. Confirmed Fear City sources auto-route to T06 + VP03 + CG-FC.
6. Fear City auto-routing is source-identity based, never resemblance based.
