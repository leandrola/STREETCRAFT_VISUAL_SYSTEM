# Archive Domain Policy

SVS 1.7 uses the Archive V1 domain vocabulary.

| Domain | Typical Streetcraft use | Default transfer posture |
|---|---|---|
| ARCHITECTURE | typology behavior, construction logic | conservative |
| STOREFRONT | segmentation, fixture behavior | conservative |
| SIGNAGE | form/material/mounting | semantics locked |
| MATERIALS | full-scale material behavior | allowed when scoped |
| WEATHERING | causal aging patterns | MID-limited |
| STREET_FURNITURE | category/placement plausibility | cautious |
| TRANSIT_INFRASTRUCTURE | structural behavior | cautious |
| INDUSTRIAL | fixtures/material logic | cautious |
| URBAN_RESIDUE | physically caused residue | cautious |
| PEOPLE_ACTIVITY | evidence of use/activity | high transfer caution |
| VEHICLES | period/category plausibility | high identity caution |
| CAMERA | camera precedent | never overrides CG-S/CG-FC |
| LIGHT_ATMOSPHERE | plausible light behavior | evidence-bounded |
| RAIN_SNOW_ASPHALT | surface/weather behavior | source-weather locked |
| TEMPORAL_LAYERING | period coexistence logic | cautious |
| REGIONAL_CHARACTER | region-specific traits | high transfer risk |

## Semantic Text Lock interaction

Archive SIGNAGE evidence may teach:
- mounting method
- sign type
- material
- scale
- typography class when justified

It may not provide invented exact wording for an unreadable source sign.

## Fear City interaction

For confirmed Fear City, Archive may support:
- material behavior
- scale cues
- light behavior
- generic period implementation

It may not supply:
- new world geometry
- New York identity
- undocumented streets
- landmarks
- exact off-frame authored content
