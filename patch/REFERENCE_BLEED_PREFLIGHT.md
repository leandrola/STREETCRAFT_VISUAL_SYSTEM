# Reference Bleed Preflight (RBP)

RBP runs **before generation** after Archive admission but before evidence is projected into the prompt/CGC.

Every transferable feature must have:
- an admitted domain
- a permitted learning scope
- a target entity or target property
- no collision with source/Scene Intelligence locks

## Reject before generation

- reference-specific geometry outside the target domain
- reference-specific props not authorized by the source/task
- camera imitation when CG-S/CG-FC is locked
- readable text imported from reference images
- geographic identity imported into Fear City
- wetness/smoke/haze/night treatment absent from the source when not authorized
- any feature whose appeal is merely global visual similarity

Reference evidence teaches a scoped property. It does not become a second source image.
