# SVS 1.9.0 Release Notes

## Release focus
Scene Intelligence.

## Why
SVS already knew how to preserve, route, retrieve references and critique outputs. Scene Intelligence makes the source itself more explicit before those decisions happen.

## New
- entity and role model
- protected relationship graph
- analytical salience
- entity-level action resolver
- SAR2
- CGC projection
- scene-derived Archive needs
- Fear City authored-world scene policy
- deterministic scene reasoning tests

## Stability gate
Automated implementation is complete.

SVS 1.8.1 policy classifies this as a behavior-changing release, therefore R2b visual candidate regression remains required for stable promotion.
