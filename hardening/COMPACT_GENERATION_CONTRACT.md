# Compact Generation Contract (CGC)

Before image generation, Streetcraft resolves the request into one compact machine-readable contract.

Required fields:

- `source_identity`
- `mode`
- `profile`
- `camera`
- `preserve`
- `transform`
- `remove`
- `infer`
- `unknown`
- `forbid`
- `semantic_text_lock`
- `material_intensity_delta`
- `occlusion_locks`

Example:

```json
{
  "source_identity": "REAL_HISTORICAL_PHOTO",
  "mode": "T01",
  "profile": "VP02",
  "camera": "CG-S",
  "preserve": ["building geometry", "sign placement", "vehicle evidence"],
  "transform": ["rendering medium"],
  "remove": [],
  "infer": [],
  "unknown": ["illegible storefront text", "occluded wall behind car"],
  "forbid": ["new signage", "new facade openings", "material intensification"],
  "semantic_text_lock": "STRICT",
  "material_intensity_delta": 0,
  "occlusion_locks": ["storefront-behind-car"]
}
```

If a request cannot be represented without contradiction, generation should stop and surface the conflict instead of silently averaging it.

## SVS 1.7 Reference Runtime Extension
The CGC may contain a `reference_runtime` block generated by the Archive-Aware Reference Runtime. Only admitted scoped evidence enters generation. Unresolved needs remain explicit.

## SVS 1.9 Scene Intelligence Extension

CGC may include a `scene_intelligence` block containing identity anchors, protected relationships, entity actions, unknown locks and Reference Need hints.

Entity-level scene actions refine, but do not weaken, existing source authority.
