# SVS 1.1 Visual Canon

Visual Canon is scoped visual evidence, not a style average. It is designed to teach an agent what Streetcraft considers strong, bounded, contextual or unacceptable without turning a reference image into a universal template.

## Canon families
- CR-A MASTER CANON: broad, high-authority Streetcraft examples.
- CR-B TRANSFORMATION CANON: source → intent → output pairs.
- CR-C DOMAIN CANON: authority restricted to a visual domain.
- CR-D PROFILE CANON: authority for a named profile such as RDR 2.0.
- CR-E NEGATIVE CANON: diagnosed failure examples.
- CR-F BOUNDARY CANON: strong references that define an upper/lower acceptable limit for a visual dimension.
- DR DOCUMENTARY EVIDENCE: real-world evidence about architecture, material behavior, signage, street use, atmosphere and temporal layering. Documentary evidence is not transformation canon.

## Authority and editorial state
Authority: GOLD / SILVER / STUDY.
Editorial state: UNREVIEWED / ACCEPTED / CANONICAL / REJECTED.
Only the human project owner may set CANONICAL.

## Core rules
SC-49 Canon Authority Is Scoped — a reference is authoritative only for properties explicitly named in its Canon Scope.
SC-50 Canon Is Evidence, Not a Style Average — multiple references inform specific problems; they are never blended into a generic Streetcraft look.
SC-51 Canon Requires Explicit Human Authority — automated scoring or agent preference cannot grant CANONICAL status.
SC-52 Historical Canon Identity Must Be Proven — historical labels such as Prototype Image cannot be assigned by resemblance alone.
SC-53 Missing Canon Is Better Than False Canon — preserve a vacancy rather than substitute a plausible but unproven historical reference.
SC-54 Documentary Reference Is Not Transformation Canon — documentary truth and transformation success are distinct authorities.
SC-55 Density Requires Causality — visual density must emerge from use, accumulation and physical relationships, not atmosphere inflation.
SC-56 Human Presence Does Not Require Humans — occupation can be evidenced through use, maintenance and routine without visible people.
SC-57 Influence Is Not Source — a documentary influence is not the direct source of a transformation unless that relationship is established.
SC-58 Temporal Layers Have Different Persistence — decades, years, months, days, hours and moments must not be treated as one temporal layer.
SC-59 Canon May Define Boundaries — a reference can be canonical for defining a limit rather than a default.
SC-60 Canon Preserves Visual Lineage — RDR Classic, RDR 2.0, Streetcraft Core and Fear City remain distinct historical stages.
SC-61 Decay Has a Source-Dependent Ceiling — decay intensity is source/profile/task dependent, never a universal Streetcraft amount.
SC-62 Graphic Form ≠ Semantic Authority — signage can teach visual form without granting authority to invented literal text.

## Canon Firewall
REFERENCE → DECLARED SCOPE → PERMITTED LEARNING → TRANSFORMATION

Never: REFERENCE → COPY EVERYTHING → TRANSFORMATION.
