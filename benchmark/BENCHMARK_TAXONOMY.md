# Benchmark Taxonomy

## B0 · Package & Schema Integrity
Checks package structure, JSON validity and required modules.

## B1 · CIL & Resolution
Checks command expansion, aliases, conflict handling and turn-scoped behavior.

## B2 · Camera Grammar & Routing
Checks CG-A / CG-B / CG-S / CG-FC routing and source-lock precedence.

## B3 · Fear City Identity & Routing
Checks confirmed / unresolved / not-applicable identity behavior and geographic locks.

## B4 · Operational Hardening
Checks Semantic Text Lock, Material Intensity Delta, Occlusion Locks, CGC and Micro-Drift Critic.

## B5 · Archive-Aware Runtime
Checks Reference Need, Archive retrieval admission, failure behavior and evidence projection.

## B6 · Visual Identity Regression
Checks source identity, geometry, camera family, text, material intensity, occlusion and reference bleed on controlled visual cases.

## B7 · Reference Isolation
Checks that retrieved evidence teaches only its declared domain and does not become global style imitation.

## B8 · Governing-File Drift
Checks protected high-authority files against the release baseline.


## B9 · Scene Intelligence
Checks entity roles, protected relationships, transient/removal logic, unknown locks, scene-to-CGC projection and scene-derived Reference Need behavior.
