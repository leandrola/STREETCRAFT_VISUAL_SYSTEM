# Archive Failure Policy

## Archive unavailable
- mark runtime `ARCHIVE_UNAVAILABLE`
- continue source-only if valid
- do not pretend model knowledge came from Archive

## Zero eligible candidates
- mark need `REFERENCE_UNRESOLVED`
- retain unknowns
- reduce transformation freedom

## Evidence conflict
- mark `EVIDENCE_CONFLICT`
- retain dissent
- do not manufacture a compromise fact

## High transfer risk
- reject or downgrade to negative-only
- never use a risky reference merely because it looks similar

## Partial bundle
A partial bundle may be used only for the domains it actually resolves.
