# Preservation Model

Preservation authority is contextual to SOURCE × TASK × MODE × PROFILE.

## Levels
P0 Identity Invariant — changing it materially breaks source identity.
P1 Character Anchor — minor adaptation possible, character must survive.
P2 Contextual Evidence — individually secondary, collectively atmospheric.
P3 Authorized Transformation — explicitly allowed to change.
P4 Authorized Removal — explicitly allowed to be removed.
P5 Reconstruction Zone — missing or occluded.

P5-A CONTINUATION
P5-B STRUCTURAL INFERENCE
P5-C CONTEXTUAL INFERENCE
P5-D UNKNOWN

## Protected Relationships
PR0 absolute
PR1 strong
PR2 contextual

Examples: sign aligned with entrance; fire escape attached to specific bays; track continuing through underpass; building adjacency.

## Epistemic classes
OBSERVED / DERIVED / INFERRED / GENERATED / UNKNOWN

Confidence: HIGH / MEDIUM / LOW / UNKNOWN

Plausibility is not observation. Unknown specificity remains unknown.
