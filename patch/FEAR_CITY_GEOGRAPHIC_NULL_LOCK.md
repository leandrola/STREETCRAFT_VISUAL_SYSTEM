# Fear City Geographic Null Lock (FC-GNL)

For `FEAR_CITY_CONFIRMED`, external geographic identity defaults to NULL.

## Allowed
- geographic/street tokens visibly authored in the Fear City source
- exact authored recurring signs already established by multi-view evidence

## Forbidden by default
- New York / NYC / Brooklyn / Manhattan / Bronx / Queens / Chicago / Boston etc.
- real-world newspaper names or mastheads
- landmarks
- transit route identities not authored in Fear City
- neighborhood names imported from Archive references

A visual resemblance to a real city is not geographic evidence.

Any imported real-world geographic identity in a normal Fear City generation is S3 `REGIONAL_LEAK`.
