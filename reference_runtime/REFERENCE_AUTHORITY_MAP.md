# Reference Authority Map (RAM) 1.0

Authority order for Archive-aware generation:

1. explicit user instruction
2. P0 source invariants
3. authored-world invariants
4. Transformation Mode
5. Visual Profile
6. Camera Grammar
7. Compact Generation Contract hard locks
8. admitted Archive Evidence Units
9. general model knowledge
10. creative preference

## Consequences

Archive evidence:
- may support a requested domain;
- may narrow an inference;
- may provide negative evidence;
- may explain period/material behavior.

Archive evidence may not:
- overwrite source geometry;
- replace visible source text;
- create geography;
- silently alter camera;
- promote itself to Canon;
- convert an inference into an observed fact.

When two Archive items conflict, the conflict remains explicit unless one source has sufficient authority to lead. Dissent remains auditable.
