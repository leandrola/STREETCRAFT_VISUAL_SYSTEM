# STREETCRAFT.md
## Entry point for AI agents
Version: SVS 1.6.2

Streetcraft is a visual transformation specification, not a generic vintage-image style and not a vendor-specific prompt recipe.

## Primary objective
Interpret a supplied source while preserving its authored or documentary identity. Transform only what the task authorizes. Prefer evidence, architectural plausibility, causal imperfection, temporal layering, restrained atmosphere and regional coherence over beautification or cinematic spectacle.

## Authority hierarchy
1. Explicit user intent
2. P0 source invariants
3. Transformation Mode
4. Visual Profile
5. Streetcraft Core Visual Grammar
6. Period and regional constraints
7. Creative preferences

Never silently average incompatible high-authority constraints.

## Mandatory execution loop
INGEST → ANALYZE → INFER → REFERENCE-REASON → RESOLVE → PLAN → GENERATE → INSPECT → DIAGNOSE → REVISE/STOP → REINSPECT

Use Visual Intelligence before generation, Visual Critic after generation, and Self-Correction only when a meaningful failure is both diagnosable and correctable within evidence and risk limits.

## Foundational principles
- Geometry before decoration.
- Ordinary architecture can carry extraordinary atmosphere.
- Age must have causes.
- Effects require causes.
- Evidence of life > props representing life.
- Atmosphere modifies reality. It does not replace reality.
- Do not improve what constitutes source identity.
- Authored imperfection is evidence, not error.
- Plausible reconstruction is not observed evidence.
- Unknown specificity must remain unknown.
- The AI is cinematographer, not production designer.
- Fear City is not raw material for redesign. Fear City is the source world.
- A beautiful image can fail Streetcraft.

## Certification
- 90–100: STREETCRAFT CANON CANDIDATE
- 80–89: STREETCRAFT PASS
- 70–79: STREETCRAFT WEAK PASS
- 60–69: REVISION REQUIRED
- 0–59: NOT STREETCRAFT

Only the human project owner can grant CANON status.
