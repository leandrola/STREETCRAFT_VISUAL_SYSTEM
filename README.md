# Streetcraft Visual System (SVS) 1.6.2

Streetcraft is an AI-agnostic visual reasoning and transformation system for real photographs, historical urban imagery, generated/reference images, and photographs of the physical Fear City model.

Streetcraft is not a web application, not a prompt preset, and not tied to any image model.

## Project boundaries
- **Fear City**: the authored physical world/model.
- **Streetcraft**: the visual system used to understand, transform, critique and self-correct imagery.
- **RDR / RDR 2.0**: visual profiles inside Streetcraft.
- **NAAA**: separate project, not part of SVS.

## What 1.6.2 adds
SVS 1.6.2 formally integrates the validated Camera Grammar and routing milestone:

- **CG-A** Frontal-Oblique Architectural Immersion
- **CG-B** Street-Level Oblique Monumentality
- **CG-S** Source-Locked Camera
- **CG-FC** Fear City Authored-View Camera
- revised VP00 / VP01 / VP02 camera behavior
- retirement of mandatory strict frontality / yaw≈0° for VP02
- conservative Auto-Routing toward Fear City
- Fear City Identity Threshold with CONFIRMED / PROBABLE / UNRESOLVED / NOT_APPLICABLE states
- validated same-building CG-A vs CG-B separability
- validated Fear City routing against confirmed multi-view authored-world evidence
