# Material Intensity Delta (MID)

MID controls how far rendered material condition may move from the observed source.

## Delta scale

- `-1` = restrained/cleaner only when explicitly justified
- `0` = source-equivalent intensity
- `+1` = modest translation required for scale/light/material realism
- `+2` = strong intensification
- `+3` = authored deterioration / cinematic inflation

## Defaults

- **T01 Faithful Reinterpretation:** `MID = 0`
- **T03 Clean Plate:** `MID = 0`
- **T06 Fear City Interpretation:** `MID <= +1` only when required to translate miniature material behavior into plausible full-scale appearance

## Forbidden silent escalations

Without explicit evidence/authority, do not add:
- wet pavement
- stronger rust
- heavier grime
- deeper cracks
- more peeling paint
- smoke/haze
- dramatic soot
- stronger graffiti density
- generalized abandonment

Atmosphere cannot disguise a material-authority violation.
